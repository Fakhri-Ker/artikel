1. Konsep Dasar Content Management System (CMS)

Pembuatan website awalnya menghadapi banyak kendala, seperti kebutuhan skrip yang banyak untuk mengatur tampilan (user-experience) maupun halaman admin (admin-experience). Jika hanya mengandalkan file HTML statis, pemeliharaannya sangat sulit, rentan merusak sistem saat proses upload melalui FTP, dan butuh pembuatan pernyataan SQL yang berulang-ulang.

Oleh karena itu, hadirlah CMS. CMS adalah sistem perangkat lunak yang memberikan kemudahan kepada penggunanya untuk mengelola, membuat, menghapus, dan memperbarui isi website dinamis tanpa perlu pengetahuan teknis pemrograman (koding). Fungsi utamanya adalah memisahkan antara konten (isi) dengan presentasi (tampilan).

3 CMS Paling Populer di Dunia:

  • WordPress: Digunakan oleh 140 juta pengguna, memiliki ribuan tema dan plugin, sangat cocok untuk blog dan web perusahaan.
  • Joomla: Memiliki 30 juta pengguna, cocok untuk situs e-commerce dan jejaring sosial.
  • Drupal: Digunakan 15 juta pengguna, berkonsep "one size fits all" yang cocok untuk berbagai kebutuhan spesifik.

2. Pengenalan dan Pengembangan Website

Website adalah kumpulan halaman yang ditampilkan di sebuah domain, disimpan dalam server hosting, dan diakses lewat internet menggunakan browser. Website dibedakan menjadi website statis (diedit manual, menggunakan format HTML) dan dinamis (diperbarui otomatis, menggunakan database, dan bahasa skrip seperti PHP).

Elemen Dasar Laman Web:

  • Header: Bagian atas yang memuat judul web, logo, dan navigasi (serta metadata pada kode HTML).
  • Content Section: Bagian utama yang menampung isi informasi atau artikel.
  • Sidebar: Kolom samping sekunder untuk menu tambahan atau artikel terbaru.
  • Footer: Bagian terbawah yang biasanya berisi hak cipta statis.

Pengembangan tahap awal bisa menggunakan komputer pribadi sebagai Local Hosting dengan aplikasi XAMPP (menjalankan Apache dan MySQL). Setelah siap, file dipindahkan ke Web Hosting menggunakan aplikasi FTP seperti FileZilla, dan datanya dikelola via PHPMyAdmin.

3. Instalasi dan Pengelolaan WordPress

Instalasi WordPress dilakukan dengan mengunduh file zip dari situs resminya, mengunggahnya ke web hosting, membuat database, dan menyambungkannya saat menjalankan instalasi via browser.

Manajemen Konten:

  • Post: Konten dinamis yang terikat oleh waktu secara kronologis (misal: berita). Menggunakan Kategori dan Tag.
  • Page: Konten statis yang tidak terikat waktu, tidak menggunakan kategori atau tag.

Manajemen Pengguna (User Level):

Pengelolaan dibagi dalam beberapa peran: Administrator mengurus teknis hosting, Editor dapat mengatur dan menerbitkan artikel semua pengguna, Author hanya bisa mengatur tulisan sendiri, dan Contributor hanya dapat menulis draf tanpa bisa mempublikasikan.

4. Praktik Terbaik dan Keamanan Web

Penting: Mengapa harus Backup Website?
Website wajib di-backup karena penyedia web hosting tidak selalu bertanggung jawab penuh. Hal ini menjaga agar Anda bisa bereaksi cepat jika terjadi peretasan (hack), memberikan rasa tenang, serta melindungi data dari infeksi virus atau malware.

Tips Desain & Keamanan (Sesuai Standar UX):

  • Format Teks Rata Kiri (Align Left): Sangat disarankan mengatur naskah teks menjadi rata kiri, bukan rata kiri-kanan (justify). Teks rata kiri lebih mudah dibaca (readable), nyaman di mata, tidak kaku, dan memang menjadi standar bagi website.
  • Sistem Komentar Disqus: Pertimbangkan memakai plugin Disqus. Fiturnya membebaskan Anda dari CAPTCHA, aman dari spam, dan memungkinkan pengunjung berdiskusi interaktif memakai akun jejaring sosial.
  • Jangan Gunakan ALL CAPS: Hindari pemakaian huruf kapital semua pada Judul Post maupun Page. All Caps sulit dipindai mata, mengesankan sedang "berteriak", dan melanggar kode etik penulisan digital. Gunakan format awalan besar (Capitalize).
  • Ganti Username 'admin' & Prefix 'wp_': Jangan gunakan username "admin" karena mudah ditebak peretas. Ubah juga prefix tabel database bawaan "wp_" dengan kombinasi angka dan huruf untuk meningkatkan sistem keamanan.
